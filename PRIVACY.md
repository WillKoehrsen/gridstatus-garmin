# Privacy

Grid Status for Garmin keeps your API key and the most recent data it fetched on your watch. Each request sends your key to the Grid Status API at `api.gridstatus.io`, in a request header. The app sends nothing else, to Grid Status or anyone else, and has no analytics.

The [Grid Status privacy policy](https://www.gridstatus.io/privacy-policy) covers how Grid Status handles API requests.
